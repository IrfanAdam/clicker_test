The new rules — steal from Supabase + Linear

◈

1 — Ghost until hover

Idle state is almost invisible. Hover is the reward.

  • lane idle dashed 6% stroke, header #F5F5F4 @ 0%
  • lane hover solid card, header amber-50 @ 52%, shadow 0 14px 30px
  • node idle 1px #D6D3D1 outline, hollow dot, dim text
  • node hover/active white + 1.6px #1C1917 + left 3px violet strip
→

2 — Lines tell the story

Thick = primary narrative, thin = plumbing. Flow shown by a traveling dot, not arrow spam.

  • Primary flow (1.8px #44403C): init → addScore → dispatch → updateUI
  • Secondary (1.25px #A8A29E): reads, binds, listeners
  • Bus lane #E7E5E4 dashed under lanes — all detours share it
  • Label pills only on hover/selection, centered on segment
⬔

3 — Heads carry kind

No rainbow. Kind is shape at the tip (Supabase pattern).

  • call — filled triangle
  • read — chevron ›
  • write — triangle + tick
  • event — diamond ◆ (dashed line)
  • bind — circle + triangle (dotted)

◈ Hover & interaction

  • Fixed: .lane--hover / .node--hover were styled on the rect but JS added class to parent <g> → hover did nothing. Now .lane-group.lane--hover .lane + .node-group.node--hover .node.
  • Fixed: Lane header double-radius seam (2× rx12 stacked → visible line at y=34). Now masking rect + single tint.
  • Fixed: rx as CSS property (invalid in Firefox) → rx/ry as SVG attributes on every rect.
  • Fixed: Label pill mouseleave always hid labels even in always mode. Now gated: only hide when labelsMode==='hover'. Buttons have aria-pressed.
  • Added: cursor:pointer, tabindex, focus styles, pointer-events:none on halos/dots/labels, transitions .18s.
